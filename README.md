# Máscaras JS

Biblioteca JavaScript para aplicação de máscaras em campos HTML de forma simples, leve e flexível sem dependência de bibliotecas externas.

---

## ✨ Funcionalidades

- Máscaras para:
  - CPF
  - CNPJ
  - Telefone
  - CEP
  - Datas
  - Valores monetários
- Aplicação automática via seletor CSS
- Compatível com JavaScript puro
- Leve e sem dependências
- Fácil integração com qualquer projeto

---

## 📦 Instalação

### Via CDN

```html
<script src="https://seudominio/js/mascaras.js"></script>
```

---

## 🚀 Como usar

### HTML

```html
<input type="text" class="mskCpf">
<input type="text" class="mskDate">
<input type="text" class="mskFone">
```

## 🎯 Máscaras disponíveis

| Tipo | Exemplo |
|------|----------|
| CPF | 000.000.000-00 |

| Telefone | (51) 99999-9999 |
